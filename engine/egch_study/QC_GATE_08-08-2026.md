## What the rebuild changed, and why

The first issue of this study was built to the retired structural template. The repository's
condensed instruction file was stale — it still named the previous exemplar — and the model
study sitting in the repository was not checked against. The consequence was a study with one
lens run in four scenarios instead of four lenses, no technical section, no probabilistic price
map, its own sheet names, an expert appendix stopping at C.3, and none of the eight depth
standards demonstrated.

Fixed in this pass: both protocol files synced to the current text; `MODEL_STUDY`,
`MODEL_STUDY_DEPTH`, `ModelStudyChecklist` and `assert_model_study()` written into
`engine/research_protocol.py` (they were referenced by the protocol but did not exist) and
verified by import; the study rebuilt to the model structure; the workbook rebuilt to the model
sheet list; a 242-input four-field register introduced and made the single source of every
number; and four programmatic depth checks added.

The underlying analysis did not change and did not need to: the filings are the same documents,
verified byte-identical, and the calibration, beta and cost-of-capital gates all passed the
first time.
