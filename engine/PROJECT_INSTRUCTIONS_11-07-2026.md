STEP 0.0 — DATA-QUALITY GATE (engine/data_quality.py; mandatory before ANY calibration, fit, or study). No series enters a panel without it. Detection is principled, not a guessed threshold: each exchange's own DAILY PRICE LIMIT defines what one session can physically do, so a move beyond it can only be a corporate action or a data error. Thresholds are PER-MARKET (EGX ±20%, Tadawul ±10%, ADX ±15%, QE ±10%, KOSPI ±30%, NSE ±20%; US/metals no limit). A GLOBAL THRESHOLD IS WRONG — an EGX-calibrated cutoff would falsely "repair" a legitimate Korean limit-down. The gate drops pre-listing/non-trading placeholder rows and back-adjusts unadjusted corporate actions. STANDING RULE: screen a market's trading-day density against that exchange's REAL calendar before trusting any fit built on it. Vendor corruption is PER-EXPORT — never assume a file is clean because another from the same vendor was. This gate exists because real corruption was found INSIDE a live production fit. STEP 0 — CALIBRATION GATE: 5-year walk-forward on the 3-month calendar window, non-overlapping windows, scored against a CARRY-ANCHORED lognormal RW benchmark (carry = ln(1+rf) − ln(1+q)), so skill can never harvest the time-value of money. The gate is SCALE-NORMALIZED (crps/spot): raw CRPS is denominated in price, so pooling it weighted every panel by SHARE PRICE, not information — one name once carried ~58% of an entire panel. Verdict is three-way and pooled: the market-panel CI is the standing gate; a name-level FAIL must be ROBUST across bootstrap block sizes {2,3,4} (a block-dependent sign flip = BOUNDARY, recorded PARITY-flagged, never a silent proceed). Break filtering applies to the CALIBRATION SAMPLE (adopted on out-of-sample evidence, not assertion). SOURCE-INTEGRITY & GROUND-UP CONSTRUCTION MANDATE (SIGCM — standing HARD GATE, every study AND every update, every ticker, every market; canonical text in Source_Integrity_and_Ground_Up_Mandate.md, machine-readable form + assert_sigcm() gate in engine/research_protocol.py). (1) HISTORICALS = OFFICIAL SOURCES ONLY: construct the past IS/BS/CF using ONLY the company's OWN issued financial statements and full disclosures — no data vendors, brokers, press-as-a-numbers-source, or third-party estimates for the subject's reported historicals (the Step 2A sweep's Global/Country/Industry rings remain fine for external context and forecast drivers, but never as the source of the company's own reported numbers). If required official data is inaccessible, STOP AND INFORM — never substitute unofficial data; NEVER issue a report based on unofficial company information. (2) FORECAST FROM THE GROUND UP: product-by-product / service-by-service wherever segments are disclosed; revenue as VOLUME × PRICE and cost as COST-PER-UNIT, with growth projected in BOTH volume and price; where unit/segment data isn't disclosed, drop to the finest sourced level and FLAG the gap (this is the same finest-sourced-level rule stated in DRIVER DISCIPLINE). (3) DEBT & FX: study balance-sheet debt in full and split local-currency vs foreign-currency tranches — consistent with the WACC rule that FX debt is carried at local-equivalent cost. (4) ASSET-CONVERSION CYCLE → BS/CF: study DSO/DIO/DPO and the cash-conversion cycle from the statements and PROJECT the balance-sheet and cash-flow items from them — no unexplained plugs where the drivers are disclosed. (5) COMPETITORS: study peers inside AND outside the country for operating KPIs and valuation multiples (cross-check / relative multiples only — never a source for the subject's historicals). (6) BETA: from the stock's OWN price history regressed against its own local index (EGX30 for EGX names) — this is the SAME beta produced by the BETA hierarchy in the WACC block, not a second method. (7) FORMULA-BASED ALWAYS: every constructed financial statement is a live formula model (driver → IS → BS → CF → DCF; blue = input / black = formula; fair value recomputes when a driver changes) — never hardcoded values. (8) FLAG-BEFORE-ISSUE / STOP: flag any missing input BEFORE the report is issued; if the website or disclosed statements can't be read and that blocks a detailed ground-up build, STOP AND INFORM — do not proceed on assumptions or unofficial substitutes. WACC (bottom-up; UNIVERSAL, PER-SOVEREIGN, PER-STOCK — see Cost_of_Capital_Reference.md + engine/wacc_builder.py, v2): EVERY country is priced off its OWN Damodaran row (Moody's/S&P rating, sovereign CDS, adjusted default spread, ERP), looked up FRESH in the ORIGINAL ctryprem.html file for that specific sovereign — Damodaran publishes every country; NEVER borrow one country's number for another or assume a region shares a figure. NORMALIZE rf — rf* = local govt-bond yield − that sovereign's OWN default spread (≈0 for mature AAA; e.g. 6.37% for Egypt Jan-2026). Country risk enters ONCE, via the CRP inside the ERP; using the raw local yield PLUS a CRP-loaded ERP DOUBLE-COUNTS sovereign risk (the systemic v1 bug that reached GBCO — re-issue affected studies). CONSISTENCY: strip the SAME basis of default spread as the CRP you add back (rating↔rating, CDS↔CDS); publish BOTH ERP-basis WACCs. rf from the local govt bond even for pegged currencies (never shortcut to USD). ERP from Damodaran's ORIGINAL file only. BETA is PER STOCK, STRICT PREFERENCE ORDER — take the first that is available: (1) OWN-STOCK 2–5yr WEEKLY/monthly regression vs its OWN local index whenever that much usable history exists (use the longest window up to 5yr; usable = passes the gate n≥24, R²≥5%, SE(β)<|β|) — FIRST CHOICE; (2) if a 2–5yr own-stock regression is NOT available (short listing, too illiquid/thin, or fails the gate), a SAME-COUNTRY peer beta (median unlevered peer β re-levered to target structure; multi-segment names → business-value-weighted unlevered β first) — never foreign peers; (3) β = 1.0 only if neither the own-stock history nor a same-country peer set is available. A daily/short-window regression is NOT one of these tiers — if ever used as a stopgap, flag it as interim and replace with tier (1) before a study is audit-clean. Kd is MARGINAL, forward-looking, and in the CASH-FLOW CURRENCY — the company's OWN latest debt issue, else local sovereign yield + corporate credit spread — and MUST sit ABOVE the local sovereign (a same-currency corporate cannot borrow below its sovereign). FX debt carried at LOCAL-EQUIVALENT cost (FX coupon + expected local depreciation), NEVER a raw FX coupon in a local-nominal WACC; NEVER a historical/accounting capitalization rate. Weights: MARKET-VALUE equity only (never book equity), book≈market for debt; normalized target structure when leverage is changing. Ke = rf* + β×ERP. Match nominal-to-nominal (real-to-real) with the cash flows; for high-inflation EM also run a USD/real valuation cross-check.
