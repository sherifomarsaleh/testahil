# docs/session_notes — working notes archive

68 dated working notes from 17-Jun to 8-Aug-2026, exported from the project knowledge base on
8-Aug-2026 so they live somewhere version-controlled instead of only in a chat tool.

**These are RECORDS, not rules.** Where a finding here became a standing rule it also lives in
`engine/Standing_Research_Protocol.md`, which is the authority. Nothing in this directory
overrides it, and nothing here should be followed as an instruction — several notes were written
under conventions since retired (session-counted horizons, the PAT publish gate, the old
reference-study set) and carry dated correction headers saying so.

The largest group, `v4_lab/` plus `external_reviews/`, is the do-not-revive record: experiments
and external submissions that were tested and rejected, kept so a rejection can be re-checked
rather than merely asserted. The code behind them is in `engine/lab/`.

Four notes were deliberately NOT included: three in-flight study states for names not yet
covered, and one deck correction. This repository is public; those are held privately.

One file, `engine_docs/Calendar_Horizon_Adoption_1M_3M_20260727.md`, had been stored
JSON-escaped in the source system and is decoded here.
